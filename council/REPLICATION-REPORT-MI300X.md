# Replication of the council's eval on CUAD: report

Run of 14/10/2026 on AMD MI300X, from 17:04 to 21:30 (Italian time). Qwen3-14B in bf16, telepathy with 0 latent steps, code `d6cbb0c` on `main`, replication pre-registration `1bcb50c`.

> **In short.** The replication on the 72 never-used CUAD test contracts **confirms G4**: the three conditions pass here too. On the replication telepathy beats text by **+7.1 F1 points** (95% interval from +2.9 to +11.6). On the total of 92 contracts it beats it by **+5.8** (from +2.1 to +9.6), with **75% fewer tokens generated** and a time of **55 s against 146 s** per contract. Against the solo agent telepathy is **on a par**: −1.2 points on the total, from −5.1 to +2.8.

## Notes on the run

- **A single execution**, with no deviations and no local changes to the code.
- **The model's code unchanged since the test.** `council.py`, `prompts.py`, `run.py`, `configurations.py`, `split.py`, `schemas.py`, `metrics.py`, `scoring.py` and `engine/` are identical to `d3c1ec1` (where they were still called `consiglio.py`, `istruzioni.py`, `esegui.py`, `configurazioni.py`, `taglio.py`, `schemi.py`, `misure.py`, `punteggio.py` and `motore/`). Since then only the loading of the replication files and the generation of the report have changed.
- **Data verified before the run.** `prepare.py` (then `prepara.py`) was redone from scratch on 14/10 with fresh downloads from the official sources: the 6 files of `measurement-set/` (then `set-di-misura/`) are byte-identical to the committed ones, and the hashes match the pre-registration.
- **A different machine from the test's,** which had already been destroyed. Host image ROCm 7.2.4 instead of 7.2. Identical container (`vllm/vllm-openai-rocm:v0.30.0`, torch 2.12, transformers 4.57.6, HIP 7.2). Two checks were done before the run:
  - G1's fp32 against bf16: the same answers on 5 problems out of 5;
  - quick trial on the demo set: telepathy F1 98.2, identical to the test.
- **Invalid verdicts: 5 of 216,** while in the test there were 0. Solo agent 1, text 2, telepathy 2. In all five cases Qwen put a Chinese character in the middle of the JSON, which therefore cannot be read. By the pre-registered rule they count as «no» on all pairs, in every configuration.
- **The 72 contracts are harder than the 20 of the test:** every configuration drops in F1. Text drops the most (−7.5), telepathy the least (−2.2). The differences should be quoted, not the absolute F1s.
- **Vote among 4 and swapped contract** are not repeated, as pre-registered: the test already measured them.
